# Mandala 3D Website - デザインと構造

## サイト全体構造

### 1. トップページ（index.html）
- **3Dヒーローセクション**: Three.jsによる曼荼羅メニュー
- **黒基調フィードセクション**: トピック/ニュース/クレジット（2025年9月30日追加）
- **9つのカテゴリ**: 円形配置、インタラクティブ操作可能

### 2. ナビゲーションシステム
#### 3D曼荼羅メニュー（メイン）
- 9つのカテゴリを3D空間に配置
- マウスドラッグ/タッチで回転
- ホイール/ピンチでズーム
- カテゴリ名のみ表示（番号なし）
- Noto Serif JP 700、白アウトライン付き

#### サブページナビゲーション（右上/右下）
- 半透明カード内に9マスグリッド
- 各番号がカテゴリページへリンク
- 200msフェード遷移
- 「曼荼羅ホーム」ラベルでトップへ

### 3. ページレイアウトパターン

#### 共通要素
- **背景**: 和紙調テクスチャ（background.jpg）
- **ヒーローセクション**: 大型タイトル、サブタイトル、説明文
- **カードレイアウト**: 半透明白背景、柔らかい影
- **フッター**: 3カラム構成（サイト情報/リンク/コピーライト）

#### ページ別特徴
- **音楽ページ**: Spotifyプレイヤー埋め込み、ライブビデオセクション
- **映像ページ**: YouTube動画グリッド、タグフィルタ機能
- **ゲームページ**: VR体験紹介、clusterワールド導線
- **リンク集**: Facebookグループカード表示

## デザイン言語

### ビジュアル階層
1. **第1階層**: ヒーロータイトル（3rem〜5rem）
2. **第2階層**: セクションタイトル（2rem〜2.5rem）
3. **第3階層**: カードタイトル（1.5rem）
4. **本文**: 1rem〜1.125rem

### インタラクション
- **ホバー効果**: transform scale(1.05)、影の強調
- **フォーカス**: アウトライン表示（アクセシビリティ）
- **遷移**: 200ms〜600msのイージング
- **スクロール**: スムーズスクロール実装

### レスポンシブ対応
- **ブレークポイント**: 768px（タブレット）、1024px（デスクトップ）
- **グリッド**: モバイル1列 → タブレット2列 → PC3〜4列
- **フォントサイズ**: clamp()による自動調整
- **3Dメニュー**: モバイル時はラベル拡大、操作簡略化
